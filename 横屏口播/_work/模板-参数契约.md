## params.json 必填

```jsonc
{
  "media": { "talk": "<母版视频绝对路径>", "captions": "<字幕 JSON 数组文件绝对路径>" },
  "brief": {
    "schema": "adu-auto-brief/1",
    "brand": "<品牌名>",
    "layout": "landscape",
    "segments": [ ... ],          // 数组，minItems 1，元素结构未在 schema 中约束
    "narrationDuration": <秒>,    // 6—600
    "header": { "shortTitle": "...", "source": { "kind": "user-explicit|assistant-summary|bound-excerpt", "field": "..." } }
  }
}
```

可选 `timeline`（不填则由 brief 推导）：`layout / duration / sourceStart / presenter.src / presenter.badge /
voiceover / subtitles / music / narrationRange{start,end} / theme{accent,accent2,warm,ok,bad,bg} /
styleProfile(light|dark) / captionAlignment(frame-center|content-center) / captionSafeArea(short-video|frame) /
segments[] / overlays[] / ending(black|cut)`。

## 字幕格式（不是 SRT）

`media.captions` 指向一个 **JSON 数组**，每行：

```jsonc
{
  "t0": 0.0, "t1": 3.0,            // 秒
  "zh": "600 个社区成员，我给他们做了一个全家福。",
  "en": "...",                      // 必填，非空；无英文可写同义短句或原文
  "highlight": {
    "source": "asr-word-boundaries",   // 或 verified-word-boundaries
    "language": "zh",
    "units": [ { "text": "600", "start": 0.0, "end": 0.4 } ]
  }
}
```

- `zh` / `en` 不允许含换行
- 每行必须有 ≥1 个 `units`
- 单词边界来自 `_work\transcript\video_*.json` 的词级时间码
