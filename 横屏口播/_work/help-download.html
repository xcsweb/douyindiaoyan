Download a template and hand it to AI

Put the template in a new working directory and ask your assistant to read its instructions.

Download and make your video

A .motion file is a video you can make again. Choose a template in the gallery and read its description, parameters, styles and license. Sign in and use the template page’s download button to get its release package.

Your personal .motion includes the template project, your account Key and a signed download source. Give it to an assistant that can actually read the file, along with your topic, text and assets. Keep the original and list outer entries read-only. Read 00-START-HERE.md and assistant/guide.json first when present, verify the bundled entry and identity, then read actual material contracts. Do not unpack personal identity or protected contents, download another Skill or host, copy an identifier, or display a Key in chat. For author projects without a bundled entry, read the actual motion.json, README, parameters, licenses and guide.json. No separate Key download or storage is needed.

Uploading to an AI assistant

  1. Wait until the attachment upload finishes before sending the template page’s prompt. A thumbnail or spinner does not confirm that the assistant has received the file.
  2. Ask the assistant to actually read it and confirm its filename, size and outer entries. If access fails, it should describe the failure rather than claim to have inspected a template shown in a screenshot.
  3. If upload keeps loading or an extension is rejected, retry or choose Download ZIP compatibility file after preparation finishes. This has exactly the same contents as the .motion from that preparation, with the same signature and account binding. It does not create another Key. A .motion file is already a ZIP container: do not wrap it in another ZIP. Both copies contain your Key and must remain private.
  4. ZIP is a compatibility option, not a guarantee that every assistant can receive or read it. If reading still fails, put the original in a new local project folder and give its accurate path to an assistant with access. Cloud tasks do not automatically receive your computer’s local files. Without file or execution tools, discuss the content and changes first, then hand the work to a capable environment.

ChatGPT Work cloud tasks can use uploaded files; local work in the desktop app depends on the account, workspace and available tools. Confirm actual file access instead of inferring production capability from a model name. Official work environment guide

Check before running

Preview the template to confirm its aspect ratio and intended use. The inspector reads package contents; rendering still needs the environment specified by the template. Confirm inputs and execution permissions, make a preview, then export. Generation APIs use your Key inside the package, which you can disable in account settings. Model provider credentials stay on the server. Share the website template link so recipients download with their own Keys. Finished videos and exported projects contain no Key.

Official tools can check for template updates and return the fixed download URL and checksum for a published new version. Signing in to download an update reuses your account Key. No download URL is offered while downloads are paused or the new version is unpublished.
