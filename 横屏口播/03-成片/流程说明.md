# 横屏口播成片流程说明

这份说明写给不需要懂代码的人：照着做就能把 8 段口播变成一条带版式、字幕、场景字卡和页头的 141.4 秒成片。

## 1. 这个模板是干什么的

`MotionGit-现代图文 · 口播讲解`（2.7.18-alpha.3）只提供**版式与动效外壳**，不生成内容：

- 它不会替你写文案、配音、剪片；
- 你的口播视频是「底片」，模板负责在底片上叠加字幕、场景字卡、页头（短标题与来源），并按 60fps 编排每一幕的时长与动效；
- 内容全部来自你的素材：母版视频、字幕 JSON、场景分段表。

所以：**内容由我们准备，画面风格由模板决定。**

## 2. 视频与模板怎么拼

```
8 段口播（01-口播素材）
      │  拼接、响度统一 -16 LUFS
      ▼
母版 master.mp4（141.4s / 1920×1080 / 30fps）
      │  拆句、对齐词级时间码
      ▼
字幕 captions.json（55 条，含逐词高亮时间）
      │  按内容切成 11 段，换算成 60fps 帧数
      ▼
场景分段（brief.segments，共 8486 帧）
      │  setup → check-params → plan → prepare → preview → render
      ▼
成片（1920×1080 / 60fps）
```

- 母版：`_work\master\master.mp4`，字幕 `_work\master\master.srt`；
- 字幕 JSON：`_work\captions.json`；
- 分段：`_work\configs\横屏口播.json` 里的 `scenes`（每幕的起止秒数）；
- 模板参数：由 `_work\adapter\native.py` 自动生成到工程实例的 `params.json`。

模板命令固定为这六步（由 `_work\pipeline.py` 自动调用，不用手敲）：

| 步骤 | 作用 |
| --- | --- |
| `setup` | 首次安装模板依赖（本机已装好，不要重复执行） |
| `check-params` | 检查参数是否合法 |
| `plan` | 把参数排成时间轴 |
| `prepare` | 把素材装配进工程 |
| `preview` | 按指定时间点抽帧，先看画面 |
| `render` | 渲染完整成片 |

## 3. 输入契约表

写入 `params.json` 的字段，含义与写法：

| 字段 | 含义 | 我们填的值 |
| --- | --- | --- |
| `media.talk` | 口播底片 | `master.mp4`（相对 `--inputs` 目录的文件名） |
| `media.captions` | 字幕 JSON（数组，逐条含 `t0/t1/zh/en/highlight`） | `captions.json`（同上） |
| `brief.segments[].durationFrames` | 每一幕的时长，单位是**帧**（60fps） | 11 段，总和 8486（`planMode=semantic`，按字幕语义自动切分） |
| `brief.header` | 页头：短标题 + 文案来源 | `shortTitle` 取发布短标题，来源写 `口播文案-横屏.txt` |
| `brief.music.mode` | 配乐绑定方式（**必须写在 `brief` 里**，放 `media` 或根级都会报错） | `{"mode":"none"}` 表示明确不使用背景音乐 |

## 4. 必须记住的五条规则

1. `durationFrames = 秒 × 60`（模板按 60fps 计），四舍五入取整。
2. 各幕帧数之和必须**正好覆盖整条口播**（141.4s → 8484 帧），多一帧少一帧都会报「场景时长没覆盖」。
3. 素材路径只能写**相对 `--inputs` 的文件名**（如 `master.mp4`），写绝对路径或带盘符会被拒绝。
4. `params.json` 必须是 **UTF-8 无 BOM**；配乐必须写在 `brief.music` 并显式声明 `none`，不能省略，也不能塞进 `media`。
5. `media` 只认 `talk` 和 `captions` 两个字段，多写别的字段会让模板读不到素材（报 `media needs talk and captions paths`）。

## 5. 常见报错中文对照

| 屏幕上的英文 | 中文含义与处理 |
| --- | --- |
| `RECOMPOSE_REQUIRED` | 场景时长之和没有覆盖整条口播：检查 8 幕的起止时间与总时长 |
| `AUDIO_CLOCK_MISMATCH` | 排片比母版音轨短：`duration` 要按母版真实音频时长，`native.py` 已自动读取 |
| `needs-binding` | 音乐未绑定，请设 `music.mode=none`（或不绑定音乐） |
| `PACKAGE_INVALID` | 参数或模板包校验失败（常见：JSON 带 BOM、路径不合法） |
| `path rejected` | 素材路径必须是相对 `--inputs` 的文件名 |
| `Input missing` | 素材不在 `--inputs` 根目录下 |
| `RUNTIME_FAILED` | 模板运行时失败，详见日志 |
| `dependency cache` | 依赖缓存缺失或损坏（需要重新执行 `setup`） |

出现问题时，先看 `_work\logs\` 下对应阶段的日志，英文原文都完整保留在里面；`python _work\pipeline.py --config _work\configs\横屏口播.json --status` 也能看到最近一次失败原因。

## 6. 怎么换模板

1. 把新的 `.zip` / `.motion` 模板包放进 `模板\` 目录；
2. 打开 `_work\configs\横屏口播.json`，把 `template.package` 改成新包的绝对路径；
3. 运行 `python _work\pipeline.py --config _work\configs\横屏口播.json --stage params`。

`native.py` 发现模板档案缺失（或模板包变了）会自动重新探测，生成新的 `_work\template-profile.json`，再按新模板的必需参数生成 `params.json`。换模板后先用 `--stage preview` 抽几帧确认版式，再渲染。

## 7. 怎么换素材

1. 把新的口播视频放进 `01-口播素材`，新的录屏放进 `02-录屏素材`（也可以在配置里改 `sources.talk` / `sources.screen` 指向别的目录）；
2. 重跑 `prep`（重新抽取音频）和 `captions`（重新生成字幕）：

```
python _work\pipeline.py --config _work\configs\横屏口播.json --from prep --force
```

3. 如果整条时长变了，记得同步修改配置里的 `narration.duration` 和 `scenes` 的起止时间，再执行 `--stage params`。

## 8. 一条命令跑全流程

```
python _work\pipeline.py --config _work\configs\横屏口播.json
```

常用附加参数：

- `--status`：只看进度、已完成产物、剩余阶段、最近一次失败；
- `--from check`：从某一阶段接着往后跑（前面已完成的会自动跳过）；
- `--stage render`：只跑某一阶段（强制执行，不受跳过规则影响）；
- `--force`：忽略「产物比输入新」的跳过规则，全部重跑；
- `--dry-run`：只打印将要执行的命令，不真正执行。

注意：`render` 渲染 141 秒成片耗时较长，确认 `preview` 抽帧没问题后再跑。

## 9. 换电脑 / 云电脑继续做

仓库里已经有：全部脚本、配置、字幕、转写、录屏插片、口播/录屏/母版视频（LFS）、模板运行时 `_work/tools-a3`。

需要你自己从本机带过去的只有两样（都不进仓库）：

1. **模板包** `模板\*.motion` / `*.zip` —— 里面含你的个人 Key，不能传 GitHub；
2. **依赖缓存**（约 340MB）—— 云上重装一次即可，别复制缓存目录。

云电脑上的步骤：

```
git clone https://github.com/xcsweb/douyindiaoyan.git
cd douyindiaoyan
git lfs pull
# 把模板包放到 横屏口播/模板/ 下
export PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple   # Windows 用 set
node 横屏口播/_work/tools-a3/assistant/motion.mjs run "<模板包绝对路径>" --instance "<新实例目录>" setup --language zh
```

`setup` 成功后用 `new` 新建实例，再把 `MOTIONGIT_INSTANCE`、`MOTIONGIT_CACHE` 指过去（环境变量优先于配置）：

```
set MOTIONGIT_INSTANCE=<新实例目录>    # Linux 用 export
set MOTIONGIT_CACHE=<依赖缓存目录>     # Linux 用 export
python 横屏口播/_work/pipeline.py --config 横屏口播/_work/configs/横屏口播.json --status
python 横屏口播/_work/pipeline.py --config 横屏口播/_work/configs/横屏口播.json --from params
```

- 配置里没有绝对根路径，`package` / `toolsDir` 都是相对 `横屏口播/` 的写法，换盘符、换系统都不用改；
- ffmpeg / ffprobe 依次找 `tools.ffmpeg` 配置、`FFMPEG`/`FFPROBE` 环境变量、系统 `PATH`，Linux 上直接装 ffmpeg 即可；
- 剪片只需要视频时，可以完全跳过模板：`01-口播素材`、`02-录屏素材` 和母版都在仓库里，用任意剪辑软件打开即可。
