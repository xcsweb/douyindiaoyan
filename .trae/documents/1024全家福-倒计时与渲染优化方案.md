# 1024 全家福：新增倒计时 + 渲染性能优化方案

## Context

页面 [index.html](file:///d:/backup-zips/www/douyindiaoyan/community-photo/index.html) 把社区 600 位 Builder 的头像做成三种版式（星座 / 地球 / 1024 点阵），支持搜索定位与导出 PNG。当前有两个问题：

1. **缺一个倒计时**：1024 是活动核心，页面里没有任何时间维度。需要在舞台上加一个秒级跳动的倒计时（目标 10/24 00:00 北京时间），到点触发庆祝并进入纪念态。
2. **数据一多就卡**：经代码核对，卡顿根因集中在三处——地球模式 `renderGlobe()`（L581-609）每帧对 600 个 DOM 节点写 `transform + opacity + zIndex`（`zIndex` 变动会触发同级样式重算，最贵）；`buildLinks()` 为 791 条连线各建一个 `<path>`；首屏一次性解码 600 张 base64 头像。

目标：地球模式改为 Canvas 渲染，彻底消除旋转卡顿；其余两模式保留 DOM，仅做定点优化；同时加入倒计时与归零庆祝。

## 一、改动清单

- `#stage` 内、`.banner`（L264）之后插入 `<div id="countdown">`

  `body[data-mode="globe"] .p { visibility:hidden; pointer-events:none }`（注意：L146 原有的 `transition:none` 规则随之失效，可一并清理）

## 二、关键设计

- **倒计时刷新**：单个 `setInterval(cdTick, 250)`，只做 `Date.now()` 差值；秒字符串未变则不写 DOM（≤4 次唤醒/秒、1 次写/秒）。**不复用 globe 的 rAF**——地球未激活时不该跑帧循环。归零即 `clearInterval` 进纪念态；额外监听 `visibilitychange` 回前台补算。
- **数字防跳宽**：`<b>` 用 `font-variant-numeric: tabular-nums` + `font-feature-settings:"tnum"` + 等宽字体栈 + 固定 `width:2ch`。
- **庆祝特效**：一次性 rAF（2.4s 后 `cancel` 并隐藏 `#fx`），2D 粒子 `globalCompositeOperation='lighter'`，从各人坐标（地球用末帧 `p.rx/p.ry`）向外爆发。头像逐一点亮用 `.lit .p .avatar::after` **只动 `opacity`** + `animation-delay`（按 `hash(i)` 在 0–900ms 抖动），**不用 `filter: drop-shadow`/`brightness`，也不给 600 个节点加 `will-change`**（会生成 600 个合成图层，反而更卡）。结束后移除 `.lit`，纪念态只靠 `body.memorial`。
- **Canvas 地球绘制顺序**：`clearRect` → 升序投影 → 跳过 `rop<=0` → `globalAlpha=rop; drawImage(disc, rx-s/2, ry-s/2, s, s)`（`s = sz*rk`）。disc 已预烘焙圆裁 + 白环，免每帧 `clip()+save/restore()` + 描边。高亮环最后叠。**canvas 尺寸只在 apply/zoom 变更**（每帧改 `width` 会清屏并重新分配）。
- **头像缓存**：`discs[p.index] = { bmp, disc }`，DOM 的 `img` 作为未就绪时的回退源，两端共用同一 disc。
- **统一交互**：`pickPerson()` 是唯一入口——地球模式用投影后的屏幕坐标做圆形命中（反向遍历取最上层），DOM 模式用 `closest('.p')`。搜索用 `hits` + `hitSet` 双写，`centerOn` 保持「DOM 滚动 / 地球旋转」分派。

## 三、风险与陷阱

1. `.p:hover { z-index:950 !important }`：若用 `opacity:0` 隐藏，节点仍可命中 → DOM 与 canvas 双命中、双 tip。**必须 `visibility:hidden` + `pointer-events:none`**（保留节点供 img/disc 复用，切回星座也不跳变）。
2. `globeHover` 唯一写入点是 `.p` 的 mouseover/mouseout（L869/885）；隐藏后 `closest('.p')` 恒为 null → 悬停不再暂停自转、`mouseout` 也不复位。**必须由 `pickPerson()` 驱动**。
3. `loading=lazy` + `createImageBitmap` 会静默 reject → 地球空白。改 eager 或先 `await decode()`；`drawImage` 保留 L1032 的 try/catch。
4. 导出与实时若各留一份投影数学会漂移，所见 ≠ 所得；**务必共用 `projectGlobe()`**。
5. `TOP_BAND` 未同步 → 星座最小 y=126 而头像半径约 19，会压住倒计时。
6. 模式残留：切出地球除已有的 `stopGlobe()` 外，还要隐藏并 `clearRect` globe canvas；切回时复位 `--inv` / `.lit` / `#fx`。
7. `resize` → `apply()` 会重建背景与连线，globe canvas 必须同步 resize；缩放滑块 `input` 高频，用 `dprEff` 阈值判断再改尺寸。
8. `globeFocus()` 会把 `globeAuto` 永久置 `false`（搜索后不再自转）——这是既有行为，不要顺手改坏。
9. 600 张 bitmap 一次做完会卡首屏，必须分批 + idle。

## 四、验证

用 Playwright（`webapp-testing`）起本地静态服务，打开页面（最终也要复测重新打包后的单文件）：

1. **帧率**（核心指标）：`addInitScript` 劫持 `requestAnimationFrame` 记时间戳；地球模式采 5s，输出帧间隔 p50/p95 与掉帧数；同时取 `page.metrics()` 的 `ScriptDuration` / `RecalcStyleCount` 增量。与优化前同脚本对比（预期帧间隔趋近 16.7ms、RecalcStyleCount 大幅下降）。
2. **三模式**：截图确认；地球模式下 `#globe` 可见且 `.p` 不可见。
3. **地球交互**：拖拽后 `globe.rotY` 变化，松手约 1.6s 恢复自转。
4. **搜索定位**：星座模式断言 `scrollLeft` 变化；地球模式断言 `rotY` 收敛到 `atan2(-s.x, s.z)` 且目标在球体正面。
5. **悬停**：`evaluate` 取 `p.rx/p.ry` 换算屏幕坐标后 `mouse.move`，断言 `#tip.on` 且内容匹配。
6. **导出**：`page.on('download')` 校验 PNG 尺寸 = `stageW*2 × stageH*2`，且球心附近非背景色。
7. **倒计时**：`addInitScript` 把 `Date.now` 偏移到 `CD_TARGET - 3s`，断言数字跳动、归零时 `body.memorial` 生效、`#fx` 先出现后隐藏、`.lit` 先加后删；再测「已过期打开」直接进纪念态；用两个 context（`Asia/Shanghai` / `America/New_York`）断言剩余秒一致（证明纯 UTC）；`reducedMotion:'reduce'` 下无自转无粒子但有纪念态。
8. **控制台**：全程收集 `pageerror` / console，断言 0 错误。
9. **重新打包**：`node build-single.mjs` 生成新的 `TRAE社区1024全家福.html`，对单文件复测第 1–7 项。注意打包脚本**不要改动** `<script src="data.js"></script>` 那一行（build-single.mjs 依赖它做替换）。
